調式練習 · 一音變身MODES PRACTICE · ONE-NOTE CHANGE

開口唱練習 · 只動一個音,換一個調式 · Move one note, change the mode

這是什麼?WHAT IS THIS

全曲 8 組、64 小節。每一組先唱來源音階,再唱只改一個音之後的新音階。被改的那個音用變化唱名(金色)。例如大調的 mi 降半音變成 me,音階就變成旋律小調。

唱名採首調唱法:主音永遠唱 do,變化的音換成變化唱名(me、le、ra、se、te),其他音不變。唱名和簡譜數字不會隨起始音改變,只有音高會跟著換。

There are 8 groups and 64 bars. Each group first sings a source scale, then the same scale with exactly one note changed. The changed note takes an altered syllable (in gold). For example, lowering mi of the major scale gives me, and the scale becomes melodic minor (ascending).

This is movable-do: the tonic is always do, and altered notes use altered syllables (me, le, ra, se, te). Syllables and numbers stay the same in every key; only the pitch moves.

怎麼練HOW TO PRACTISE

先聽一遍,第二遍開始跟著唱。注意金色那個唱名:來源音階唱到它的位置時,下一遍就換成變化唱名。聽出這一個音的差別,就聽出調式的差別。8 組唱完,換一個起始音再來。

Listen once, then sing along. Watch the gold syllable: where the source scale has the old note, the second pass has the altered one. Hearing that one note is hearing the mode change. After all 8 groups, pick a new starting note and go again.
